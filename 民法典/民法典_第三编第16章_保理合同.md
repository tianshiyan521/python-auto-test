# 📖 民法典 · 第三编 第16章 保理合同（第761-769条）

## 【核心条款精选】

**第761条**：保理合同是应收账款债权人将现有的或者将有的应收账款转让给保理人，保理人提供资金融通、应收账款管理或者催收、应收账款债务人付款担保等服务的合同。
👉 大白话：你把"别人欠你的钱"打包卖给保理公司，它先给你现金，再自己去收账——用未来的钱换现在的钱。

**第762条**：保理合同的内容一般包括业务类型、服务范围、服务期限、基础交易合同情况、应收账款信息、保理融资款或者服务报酬及其支付方式等条款。保理合同应当采用书面形式。
👉 大白话：必须签书面合同，业务类型（有没有追索权）等关键条款要写清，这是全章最容易出争议的地方。

**第763条**：应收账款债权人与债务人虚构应收账款作为转让标的，与保理人订立保理合同的，应收账款债务人不得以应收账款不存在为由对抗保理人，但是保理人明知虚构的除外。
👉 大白话：⭐你和欠款人合谋编造一笔根本不存在的应收账款去融资，被追债时不能再拿"这钱本来就不存在"当挡箭牌——但保理公司明知是假的除外。

**第764条**：保理人向应收账款债务人发出应收账款转让通知的，应当表明保理人身份并附有必要凭证。
👉 大白话：保理公司来通知你"以后钱还给我"，得先亮明身份、拿出凭证，否则你可以不认。

**第765条**：应收账款债务人接到应收账款转让通知后，应收账款债权人与债务人无正当理由协商变更或者终止基础交易合同，对保理人产生不利影响的，对保理人不发生效力。
👉 大白话：通知送达后，买卖双方偷偷改合同、缩金额，想坑保理公司——这种改动对保理公司不算数。

**第766条**：当事人约定有追索权保理的，保理人可以向应收账款债权人主张返还保理融资款本息或者回购应收账款债权，也可以向应收账款债务人主张应收账款债权。保理人向应收账款债务人主张应收账款债权，在扣除保理融资款本息和相关费用后有剩余的，剩余部分应当返还给应收账款债权人。
👉 大白话：有追索权＝"保底模式"，钱收不回来还能回头找你要，你等于只是借了一笔有担保的钱。

**第767条**：当事人约定无追索权保理的，保理人应当向应收账款债务人主张应收账款债权，保理人取得超过保理融资款本息和相关费用的部分，无需向应收账款债权人返还。
👉 大白话：无追索权＝"卖断模式"，钱收不回来保理公司自己认亏，多收的也不用还你。

**第768条**：应收账款债权人就同一应收账款订立多个保理合同，致使多个保理人主张权利的，已经登记的先于未登记的取得应收账款；均已经登记的，按照登记时间的先后顺序取得应收账款；均未登记的，由最先到达应收账款债务人的转让通知中载明的保理人取得应收账款；既未登记也未通知的，按照保理融资款或者服务报酬的比例取得应收账款。
👉 大白话：一笔应收账款跟多家保理公司签合同，抢钱顺序是：登记的先拿 → 都登记按登记先后 → 都没登记按谁先通知 → 都没通知按出资比例分。

**第769条**：本章没有规定的，适用本编第六章债权转让的有关规定。
👉 大白话：保理本质是债权转让，本章没讲的，按"债权转让"那套规则办。

## 【通俗解读】

- **一句话搞懂保理**：核心是"卖应收账款换现金"。你给大厂供货，账期 90 天，资金压得慌，就把这张欠条打折卖给保理公司，先拿到钱去周转。
- **有追索权 vs 无追索权（本章最关键的区别）**：
  - **有追索权**：收不回来能回头找卖家要 → 对保理公司安全，对卖方相当于质押融资
  - **无追索权**：收不回来自己扛 → 对保理公司风险大（所以费率更高），对卖方是真正的"卖断出表"
- **什么时候用上**：中小企业给大客户供货后资金紧张；企业做供应链金融；帮企业把应收账款从账上"变出"现金。
- **三条避坑提醒**：
  1. 别虚构应收账款去融资（763条）——合同相对方不能拿"不存在"抗辩，还可能涉刑
  2. 签多份保理合同要想清楚顺序（768条）——**先登记占先机**
  3. 收款方收到转让通知后别乱改基础合同（765条）——改了也不对抗保理公司

## 【一句话记住这章】

**"欠条卖给保理公司换现金：有追索能回头找你，无追索自负盈亏；通知送达别乱改合同，同一笔账先登记者先拿。"**
