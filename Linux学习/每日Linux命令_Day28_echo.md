# 每日Linux命令 · Day 28/30

**【命令】**
`echo - 输出文本`

**【基本语法】**
```bash
echo [选项] [字符串]
```

**【常用示例】**

1. 基础用法 — 输出一行文本
```bash
echo "Hello World"
# 输出：Hello World

echo Hello World
# 不加引号也行，输出一样：Hello World
```

2. 带选项用法 — 解析转义字符 / 不换行
```bash
# -e 解析转义字符（换行 \n、制表符 \t 等）
echo -e "第一行\n第二行\n第三行"
# 输出三行

echo -e "姓名\t年龄\t成绩\n张三\t25\t90"
# 输出带制表符对齐的表格

# -n 不在末尾换行（常用于脚本中拼接同一行输出）
echo -n "正在加载..."
echo "完成"
# 输出：正在加载...完成（同一行）
```

3. 实际工作场景 — 写入文件 / 追加内容
```bash
# 配合 > 覆盖写入文件
echo "127.0.0.1 myserver" > /etc/hosts.d/local
# 文件内容变成这一行（原有内容被覆盖）

# 配合 >> 追加到文件末尾
echo "[$(date '+%Y-%m-%d %H:%M:%S')] 部署完成" >> deploy.log
# 在日志文件末尾追加一条带时间戳的记录

# 写入多行配置
echo -e "[mysql]\nhost=127.0.0.1\nport=3306\nuser=root" > db.conf
```

4. 实际工作场景 — 脚本中输出变量和命令结果
```bash
# 输出环境变量
echo "当前用户：$USER"
echo "HOME目录：$HOME"
echo "当前路径：$PWD"

# 输出命令执行结果（反引号或 $()）
echo "今天日期：$(date +%Y-%m-%d)"
echo "当前进程数：$(ps aux | wc -l)"

# 脚本中打印调试信息
echo "[INFO] 开始执行数据库备份..."
echo "[INFO] 备份文件大小：$(du -sh backup.sql | cut -f1)"
echo "[DONE] 备份完成，路径：/data/backup/backup_$(date +%Y%m%d).sql"
```

5. 实际工作场景 — 颜色输出（脚本美化）
```bash
# 红色错误信息
echo -e "\033[31m[ERROR] 数据库连接失败！\033[0m"

# 绿色成功信息
echo -e "\033[32m[SUCCESS] 部署完成！\033[0m"

# 黄色警告信息
echo -e "\033[33m[WARN] 磁盘使用率超过80%\033[0m"
```

**【选项说明】**

| 选项 | 说明 | 示例 |
|------|------|------|
| `-n` | 输出后不换行 | `echo -n "加载中..."` |
| `-e` | 解析转义字符（\n \t \\ 等） | `echo -e "A\nB\nC"` |
| `-E` | 不解析转义字符（默认行为） | `echo -E "A\nB"`（原样输出） |

**【常用转义字符】**（配合 `-e` 使用）

| 转义符 | 含义 | 示例 |
|--------|------|------|
| `\n` | 换行 | `echo -e "行1\n行2"` |
| `\t` | 水平制表符 | `echo -e "A\tB\tC"` |
| `\\` | 输出反斜杠本身 | `echo -e "C:\\Users"` |
| `\033[颜色m` | ANSI颜色码 | `echo -e "\033[31m红字\033[0m"` |

**【注意事项】**

- ⚠️ **`echo` 的行为在不同 shell 中不一致**：Bash 的 `echo` 支持 `-e` 和 `-n`，但 `/bin/sh`（Dash）的 `echo` 默认就解析转义字符，且不一定支持 `-e`。如果脚本 `#!/bin/sh`，建议改用 `printf` 来保证跨平台一致性。
- ⚠️ **引号的区别**：双引号 `"..."` 会解析变量和命令（`$VAR`、`$(cmd)`），单引号 `'...'` 原样输出不解析。`echo '$HOME'` 输出的是 `$HOME` 这四个字符，而不是家目录路径。
- ⚠️ **`>` 和 `>>` 要分清**：`>` 是覆盖写入，文件原有内容直接没了；`>>` 是追加。写错的话数据就没了，对重要文件操作前先备份。
- 💡 **想输出带 `$` 的字符串**：用单引号 `echo '$USER'` 或者转义 `echo "\$USER"`，否则会被当成变量解析。

**【一句话记住它】**

> echo 就是 Linux 的"喇叭"——你说什么它喊什么，还能配合 `>` 和 `>>` 把说的话写到文件里，是写脚本打日志的第一工具。
