## 【命令】
`kill` — 终止进程

---

## 【基本语法】
```bash
kill [选项] <PID>
```

PID 是进程 ID（Process ID），可以通过 `ps` 或 `top` 查到。

---

## 【常用示例】

### 1. 优雅终止进程（默认信号 SIGTERM = 15）
```bash
kill 12345
```
发给进程一个「请你退出」的信号，进程有机会清理资源后再退出。

### 2. 强制杀死进程（SIGKILL = 9）
```bash
kill -9 12345
```
不商量，直接杀掉。进程没有任何清理机会，**只有卡死无响应时才用这个**。

### 3. 按进程名批量终止
```bash
# 先查进程
ps aux | grep nginx

# 用 killall 按名称终止（所有同名进程）
killall nginx

# 或者用 pkill 模糊匹配
pkill -f "python my_script.py"
```
测试场景：游戏服务器卡死、压测脚本死循环，用这个快速清场。

### 4. 批量杀僵尸进程
```bash
ps aux | grep defunct | awk '{print $2}' | xargs kill -9
```
清理那些父进程没回收的僵尸进程（状态 Z）。

---

## 【选项说明】

| 选项 | 说明 | 示例 |
|------|------|------|
| `-l` | 列出所有信号名称 | `kill -l` |
| `-9` / `-KILL` | 强制杀死（SIGKILL） | `kill -9 12345` |
| `-15` / `-TERM` | 优雅终止（默认） | `kill -15 12345` |
| `-1` / `-HUP` | 重新加载配置（不杀进程） | `kill -1 12345` |
| `-2` / `-INT` | 模拟 Ctrl+C 中断 | `kill -2 12345` |

---

## 【常用信号速查】

| 信号编号 | 信号名 | 作用 |
|----------|--------|------|
| 1 | SIGHUP | 挂起，常用于让进程重读配置 |
| 2 | SIGINT | 中断（等同于 Ctrl+C） |
| 9 | SIGKILL | **强制杀死，不可捕获** |
| 15 | SIGTERM | 终止（默认，可被进程捕获） |
| 17 | SIGSTOP | 暂停进程 |
| 18 | SIGCONT | 恢复暂停的进程 |

---

## 【注意事项】

- ⚠️ **`kill -9` 是最后手段**：优先用 `kill -15`（默认），-9 不给进程清理机会，可能导致数据丢失、临时文件残留。
- ⚠️ **别杀错了**：确认 PID 再下手，尤其是 `kill -9` 无法撤销。用 `ps aux | grep xxx` 双重确认。
- ⚠️ **kill -9 对 init(PID=1) 无效**：系统关键进程不允许被 -9 杀死。
- 💡 **测试场景**：游戏挂机脚本跑飞 → `ps aux | grep game_bot` → `kill 12345`，别上来就 -9。

---

## 【一句话记住它】

> **kill 不是「杀」进程，是「发信号」——默认发的是「请你自己退出」的通知，-9 才是真的拔电源。**
