# 🐧 今日Linux命令 · Day 23/30

**【命令】**
`free - 内存使用`

---

**【基本语法】**
```bash
free [选项]
```

---

**【常用示例】**

1. **基础用法**：直接查看内存（默认单位为 KiB）
   ```bash
   free
   ```

2. **带选项用法**：以人类可读的方式显示
   ```bash
   free -h
   ```

3. **实际工作场景**：持续监控内存，每 5 秒刷新一次
   ```bash
   free -h -s 5
   ```
   或者配合 `watch` 实时刷新：
   ```bash
   watch -n 1 free -h
   ```

---

**【选项说明】**

| 选项 | 说明 | 示例 |
|------|------|------|
| `-h` | 以人类可读的单位显示（如 GiB/MiB） | `free -h` |
| `-m` | 以 MB 为单位显示 | `free -m` |
| `-g` | 以 GB 为单位显示 | `free -g` |
| `-s N` | 每 N 秒刷新一次 | `free -h -s 5` |
| `-t` | 显示总计行（total） | `free -ht` |

---

**【注意事项】**
- **free 和 available 的区别**：`free` 是完全没有被使用的内存；`available` 是程序可以立即使用的内存，包含了缓存和缓冲。判断内存够不够，重点看 **available**。
- 看到 `used` 很高不用慌，Linux 会把空闲内存用作缓存（buffers/cache），系统需要时会自动释放。
- `free` 本身没有破坏性，属于安全查询命令。

---

**【一句话记住它】**
`free` 就是问系统：“现在还剩多少内存能让我可劲儿造？”
