# 🐧 今日Linux命令 · Day 24/30

**【命令】**
`ping - 网络连通性`

---

**【基本语法】**
```bash
ping [选项] 目标地址
```

---

**【常用示例】**

1. **基础用法**：测试与某台服务器是否连通
   ```bash
   ping 192.168.1.100
   ```
   持续发包，按 `Ctrl+C` 手动停止。

2. **带选项用法**：指定发包次数（测 4 次就停）
   ```bash
   ping -c 4 baidu.com
   ```

3. **实际工作场景**：
   - **排查部署环境连通性**：游戏服务器上线前，先 ping 一下目标机器确认网络可达
     ```bash
     ping -c 3 10.0.0.50
     ```
   - **指定发包间隔**：慢速 ping，避免触发防火墙限速
     ```bash
     ping -i 2 -c 10 target-server.com
     ```
   - **设置超时时间**：等不到回复就认为失败，适合快速检测
     ```bash
     ping -W 1 -c 3 192.168.10.20
     ```

---

**【选项说明】**

| 选项 | 说明 | 示例 |
|------|------|------|
| `-c N` | 发 N 个包后停止 | `ping -c 4 baidu.com` |
| `-i N` | 每隔 N 秒发一个包（默认1秒） | `ping -i 2 10.0.0.1` |
| `-W N` | 等待回复超时 N 秒 | `ping -W 1 -c 3 192.168.1.1` |
| `-s N` | 设置数据包大小（默认64字节） | `ping -s 1000 target.com` |
| `-q` | 安静模式，只输出汇总统计 | `ping -q -c 10 baidu.com` |

---

**【注意事项】**
- **部分服务器禁 ping**：很多生产环境防火墙会丢弃 ICMP 包，ping 不通不代表服务不可达。此时可用 `curl` 或 `telnet` 进一步验证端口是否开放。
- **不要长时间 ping 公网地址**：持续 ping 可能触发对方防火墙的限速/封禁策略，建议加 `-c` 指定次数。
- **`ping` 是安全命令**，本身没有破坏性，但滥用可能被视为网络骚扰。

---

**【一句话记住它】**
`ping` 就像给远方的朋友喊一声"喂，在吗？"——通了就回你，不通就沉默。
