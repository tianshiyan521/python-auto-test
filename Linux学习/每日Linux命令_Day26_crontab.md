# 每日Linux命令 · Day 26/30

**【命令】**
`crontab - 定时任务`

**【基本语法】**
```bash
crontab [选项]
```

**【常用示例】**

1. **查看当前用户的定时任务**
```bash
crontab -l
```
输出类似：`0 6 * * * /home/user/backup.sh`，表示每天6点执行备份脚本。

2. **编辑当前用户的定时任务**
```bash
crontab -e
```
打开编辑器（通常是vim），写入任务规则后保存即可生效。

3. **实际工作场景：游戏服务器日常维护**
```bash
# 每天凌晨3点清理日志
0 3 * * * /opt/game/scripts/clean_logs.sh

# 每周一凌晨2点做数据库备份
0 2 * * 1 /opt/game/scripts/db_backup.sh

# 每5分钟检查服务是否存活，挂了就重启
*/5 * * * * /opt/game/scripts/health_check.sh
```

**【选项说明】**

| 选项 | 说明 | 示例 |
|------|------|------|
| `-e` | 编辑当前用户的crontab任务 | `crontab -e` |
| `-l` | 列出当前用户的所有任务 | `crontab -l` |
| `-r` | 删除当前用户的所有任务 | `crontab -r` |
| `-u` | 操作指定用户的crontab（需root权限） | `crontab -u gameadm -l` |

**【时间格式速查】**

```
┌──────── 分钟 (0-59)
│ ┌────── 小时 (0-23)
│ │ ┌──── 日 (1-31)
│ │ │ ┌── 月 (1-12)
│ │ │ │ ┌ 星期 (0-7，0和7都=周日)
│ │ │ │ │
* * * * * 命令
```

| 符号 | 含义 | 示例 |
|------|------|------|
| `*` | 每（所有值） | `* * * * *` = 每分钟 |
| `,` | 列举多个值 | `0 8,12,18 * * *` = 每天8/12/18点 |
| `-` | 范围 | `0 9-17 * * 1-5` = 工作日9到17点 |
| `/` | 步长 | `*/10 * * * *` = 每10分钟 |

**【注意事项】**

- ⚠️ **`crontab -r` 无确认直接删除所有任务！** 误操作后只能重新配置，没有回收站。建议先 `crontab -l > my_crontab_backup.txt` 备份再操作。
- crontab 里的命令**不会加载你的 shell 环境变量**（PATH 可能不同）。脚本里最好写绝对路径，比如 `/usr/bin/python3` 而不是 `python3`。
- cron 的最小执行间隔是1分钟，不能做到秒级定时。需要秒级可以用 `sleep` 循环或其他方案。

**【一句话记住它】**
crontab 就是 Linux 的"闹钟"——定时自动干活，不用你盯着。
