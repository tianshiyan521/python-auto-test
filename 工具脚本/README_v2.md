# 微信自动回复系统 v2.0

基于 **itchat-uos**（微信网页版API）的自动回复系统，无需微信窗口在前台，更稳定可靠！

## 🎯 **相比v1.0的优势**

| 特性 | v1.0（wxauto） | v2.0（itchat-uos） |
|------|---------------|-------------------|
| 微信窗口 | 必须在前台 | 无需窗口，后台运行 |
| 登录方式 | 电脑客户端登录 | 手机扫码登录网页版 |
| 稳定性 | 较低，容易被检测 | 较高，基于官方API |
| 跨平台 | 仅Windows | Windows/macOS/Linux |
| 部署难度 | 中等 | 简单 |

## 🚀 **快速开始**

### **方法1：一键安装（推荐）**
直接双击 `install_v2.bat`，然后按提示操作。

### **方法2：手动安装**
1. 安装依赖：
   ```bash
   pip install itchat-uos==1.5.0.dev0
   ```
2. 运行程序：
   ```bash
   python wechat_auto_reply_v2.py
   ```

### **方法3：使用启动脚本**
双击 `start_wechat_v2.bat`

## 📱 **登录流程**

1. 运行程序
2. 命令行会显示二维码
3. 使用**手机微信**扫描二维码
4. 在手机上确认登录
5. 系统开始自动回复

**注意**：首次登录后，会在目录下生成 `itchat.pkl` 文件，下次启动可能无需再次扫码。

## ⚙️ **配置说明**

### **主要配置文件** `wechat_config_v2.json`

#### 1. 回复规则（reply_rules）
```json
{
  "keywords": ["你好", "在吗"],
  "reply": "你好！我是自动回复助手...",
  "enabled": true
}
```

#### 2. 自动回复设置（auto_reply_settings）
```json
{
  "enabled": true,                    // 总开关
  "reply_to_friends": true,          // 回复好友
  "reply_to_strangers": false,       // 回复陌生人
  "reply_to_groups": false,          // 回复群聊
  "max_reply_per_conversation": 3,   // 每个对话最大回复次数
  "working_hours": {                 // 工作时间段
    "start": "09:00",
    "end": "22:00"
  }
}
```

#### 3. 登录设置（login_settings）
```json
{
  "hot_reload": true,               // 热重载，避免每次扫码
  "status_storage_dir": "itchat.pkl", // 登录状态保存文件
  "enable_cmd_qr": true             // 在命令行显示二维码
}
```

## 🔧 **自定义配置**

### **添加新的回复规则**
在 `reply_rules` 数组中添加新的规则对象：
```json
{
  "keywords": ["约饭", "吃饭去"],
  "reply": "好啊！等主人回来告诉他/她~",
  "enabled": true
}
```

### **修改工作时间**
```json
"working_hours": {
  "start": "08:30",
  "end": "20:00"
}
```

### **开启群聊回复**
```json
"reply_to_groups": true
```

### **调整回复限制**
```json
"max_reply_per_conversation": 5  // 每个对话最多回复5次
```

## 🛠️ **故障排除**

### **问题1：二维码显示异常**
**解决方案：**
1. 调整命令行窗口大小
2. 使用 Windows Terminal（微软商店下载）
3. 修改配置：`"enable_cmd_qr": false`
4. 检查网络连接

### **问题2：扫码后无法登录**
**解决方案：**
1. 检查手机网络
2. 确认微信版本（建议最新版）
3. 清除登录状态文件：`itchat.pkl`
4. 重启程序

### **问题3：无法回复消息**
**解决方案：**
1. 检查是否在工作时间段内
2. 检查回复对象设置
3. 查看消息历史记录文件
4. 开启调试模式：`"debug_mode": true`

### **问题4：频繁掉线**
**解决方案：**
1. 保持网络稳定
2. 定期重启程序（建议每天一次）
3. 检查微信网页版是否被踢出

## 📝 **使用建议**

### **最佳实践**
1. **工作时间设置**：9:00-18:00工作时间，其余时间不打扰
2. **回复限制**：每个对话最多回复3次，避免刷屏
3. **关键词精简**：选择最常用的关键词
4. **定期维护**：每周检查一次消息历史，调整回复规则

### **隐私保护**
1. 消息历史包含聊天内容，注意文件保管
2. 不要分享 `itchat.pkl` 登录文件
3. 定期清理历史记录
4. 敏感信息不要配置在回复规则中

### **性能优化**
1. 关闭不必要的日志输出
2. 定期清理历史记录文件
3. 使用稳定的网络环境
4. 避免同时登录多个微信账号
