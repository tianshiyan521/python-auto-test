# 微信自动回复系统

这是一个基于 wxauto v4 的微信自动回复系统，可以帮你自动回复微信消息。

## 功能特点

- ✅ 自动监控微信新消息
- ✅ 智能关键词匹配回复
- ✅ 可自定义回复规则
- ✅ 工作时间段控制
- ✅ 消息历史记录
- ✅ 支持群聊/私聊过滤

## 使用方法

### 1. 安装依赖
```bash
pip install wxauto==4.0.0
```

### 2. 准备微信客户端
- 确保微信已登录
- 微信窗口需要在前台可见（不能最小化）
- 建议将微信窗口调整到合适大小

### 3. 运行自动回复
```bash
python wechat_auto_reply.py
```

### 4. 配置说明
配置文件 `wechat_config.json` 包含以下设置：

#### 回复规则 (reply_rules)
```json
{
  "keywords": ["你好", "在吗"],
  "reply": "你好！我是自动回复助手...",
  "enabled": true
}
```

#### 自动回复设置 (auto_reply_settings)
```json
{
  "enabled": true,                    // 总开关
  "check_interval": 2.0,             // 检查间隔（秒）
  "working_hours": {                 // 工作时间段
    "start": "09:00",
    "end": "22:00"
  },
  "ignore_groups": true,             // 是否忽略群聊
  "max_reply_per_conversation": 3,   // 每个对话最大回复次数
  "reply_to_friends": true,          // 回复好友
  "reply_to_strangers": false        // 回复陌生人
}
```

## 自定义配置

### 添加新的回复规则
在 `wechat_config.json` 的 `reply_rules` 数组中添加：

```json
{
  "keywords": ["吃饭", "午饭", "晚饭"],
  "reply": "主人正在忙，还没吃饭呢~ 你吃了吗？",
  "enabled": true
}
```

### 修改工作时间
```json
"working_hours": {
  "start": "08:30",
  "end": "20:00"
}
```

### 启用调试模式
```json
"debug_mode": true
```

## 高级功能

### 1. 消息历史
- 所有自动回复的消息都会保存在 `wechat_history.json`
- 包含时间、发送者、消息内容、回复内容

### 2. 智能回复
- 根据消息长度选择不同回复
- 问题消息特别标识
- 长消息特别处理

### 3. 安全过滤
- 忽略系统消息
- 忽略空消息
- 忽略群聊（可配置）
- 忽略自己发送的消息

## 注意事项

1. **微信窗口必须可见**：wxauto 需要微信窗口在前台才能正常工作
2. **权限问题**：确保 Python 有权限访问微信窗口
3. **防封号**：不要设置过于频繁的回复，避免被微信检测
4. **隐私保护**：消息历史包含聊天内容，注意保管
5. **测试模式**：首次运行时可以使用调试模式测试

## 故障排除

### 问题：无法连接到微信
- 解决方案：确保微信已登录且窗口在前台
- 检查是否有多个微信进程

### 问题：无法发送消息
- 解决方案：检查微信输入框是否可见
- 尝试手动切换聊天窗口

### 问题：回复太频繁
- 解决方案：调整 `check_interval` 到更大的值
- 限制每个对话的回复次数
